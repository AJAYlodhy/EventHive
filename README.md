# EventHive — Campus & Tech Event Management System

EventHive is a modern, modular Event Management Platform designed for Universities, Tech Clubs, and Event Organizers.

## Module: Organizer / Host (`feature/organizer`)

The Organizer module is fully developed and tested on this branch.

### Quick Start Guide

#### 1. Start Backend API
```bash
cd backend
npm install
npm start
```
* API Server: `http://localhost:5000`
* Run automated tests: `npm test`

#### 2. Start Frontend App
```bash
cd frontend
npm install
npm run dev
```
* Web App: `http://localhost:3000`
